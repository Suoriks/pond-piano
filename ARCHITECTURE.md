# Architecture hypothesis v0

## Решение

Начать с installable offline-first PWA на TypeScript. Причина — максимальная переносимость между desktop/Linux/Android/iOS и быстрый цикл дизайна. Не добавлять Capacitor/Tauri до измеренного ограничения браузера.

## Слои

1. **Gesture field** — Pointer Events, pointer capture, нормализация x/y/pressure/velocity, карта активных касаний.
2. **Musical mapping** — чистые функции координаты → pitch/timbre/gain; строи и квантование не знают о DOM.
3. **Audio engine** — Web Audio AudioWorklet по мере необходимости; сначала малый полифонический движок с master limiter и корректным lifecycle iOS.
4. **Pond renderer** — Canvas/WebGL после сравнительного spike; аудио не зависит от частоты кадров.
5. **Shell** — PWA manifest, service worker, настройки, доступность, сохранение локальных предпочтений.

## Границы

- Никакого сетевого backend для игры.
- Никакого UI-фреймворка до появления сложности, оправдывающей его.
- Аудио-время — источник истины для звука; визуал может деградировать без заикания аудио.
- Feature detection вместо user-agent ветвления.

## Доказано прототипом

- Оболочка устанавливается как standalone PWA и после первого открытия полностью перезагружается без сети.
- App shell кэшируется отдельно от аудио/рендеринга; навигация предпочитает свежую версию и откатывается к локальной.
- Иконки генерируются из одного воспроизводимого водного мотива, включая maskable и Apple touch варианты.
- Multi-touch создаёт до шести независимых Web Audio голосов; общий уровень нормализуется по числу голосов, а аудиоузлы освобождаются только после короткого release.
- Визуальный аккорд строится из парных узлов интерференции между активными касаниями и остаётся читаемым в `prefers-reduced-motion` без зависимости аудио от renderer.
- Координатная высота и мягкое притяжение к пентатоническому строю вынесены в чистый `pond-music.js`: движение остаётся непрерывным, а после короткой выдержки звук и локальные каустики сходятся к ближайшему течению; слой проверяется отдельно от DOM и Web Audio.
- Короткая водная партитура вынесена в чистый `pond-score.js`: траектории нормализованы относительно viewport, ограничены 24 точками и 12 жестами, живут 18 секунд (9 при reduced motion) и не удерживают DOM/Audio-объекты.
- Та же чистая модель группирует память в мотивы по временному перекрытию и паузе 1,4 секунды независимо от порядка отпускания голосов; renderer соединяет только окончания жестов одного мотива органичным подводным течением, а доступный статус сообщает начало нового.

## Риски, которые доказываем прототипами

- iOS Safari: unlock/resume AudioContext и надёжный multi-touch.
- Задержка Bluetooth-аудио неизбежна; интерфейс не должен обещать невозможное.
- Canvas 2D против WebGL: сначала красота и устойчивые 60 fps на среднем телефоне, потом выбор.
- Pointer pressure непоследователен: velocity fallback обязателен.
